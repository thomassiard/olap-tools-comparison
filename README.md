Diplomski rad koji analizira i uspoređuje pet OLAP (Online Analytical Processing) alata na primjeru stvarnog skupa podataka. Cilj rada je istražiti prednosti, mane i praktičnu primjenjivost svakog alata za analizu i vizualizaciju podataka.

Rad uspoređuje sljedećih **5 OLAP alata**:

1. Power BI
2. Tableau
3. Apache Superset
4. Metabase
5. ClickHouse

Alati se uspoređuju prema kriterijima poput: performansi (brzina upita), jednostavnosti korištenja, mogućnosti vizualizacije, cijene/licenciranja, skalabilnosti i podrške zajednice.
